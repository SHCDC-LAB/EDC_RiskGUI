2026-10-29 更新与升级方法
已有1.0环境时：将新版EDC_AOPRisk_GUI文件夹与原同名文件夹合并覆盖，保留原有.venv文件夹，无需重新安装依赖。之后双击Start_Windows.bat。
每次启动先核对分子特征和3个升级模型的12个示例概率。自检通过才打开GUI；预测开始时还会复核。自检失败时会停止，不继续生成看似正常的预测结果。
启动自检资料为软件目录内Startup_Runtime.json和Startup_Diagnostic.log；运行中的诊断资料随结果保存。若启动失败，请提供这两个文件。程序不会自动上传。

本次修正
1. 修复Windows + NumPy 2下BertzCT整数计数的兼容性问题：明确使用float64传入熵计算，沿用RDKit原公式。这与RDKit官方修复思路一致。
2. 保留1.0.1的85项片段定义恢复、RDBASE隔离，以及215项扩展特征和12个示例概率的数值自检。
3. 启动脚本统一使用UTF-8，避免诊断日志中文乱码。
4. 模型活性概率、数据库实测pAC50和模型预测pAC50仍分别显示，双击终点行可查看详情。

本轮验证
用户1.0.1启动日志中的3个BertzCT差值，均可由整数熵错误返回零这一缺陷精确复现。结合此前片段特征缺失的模拟，原Windows示例的3模型×4结构共12个概率（含11处异常）全部复现。
修复后，在本地注入相同整数计算故障并设置无效RDBASE，完整重跑论文246个结构。41个终点的10,086条原始结果和17个EATS终点的4,182条筛选结果均与已核验参考结果一致，仍为21个关注条目。原模型权重、科学预测脚本、参考特征及筛选阈值未改变。
本轮是Linux上的故障复现和回归测试；用户Windows实机通过与否以新版启动自检为准。仍请用新版重算旧版预测过的自定义化合物。

先读这几步（Windows 10/11，64位）
1. 将整个ZIP完整解压到有写入权限的目录。不要在压缩包内直接双击运行。
2. 本稿是GUI运行包，不是已编译、免Python的EXE。先安装64位Python 3.12或3.13，并安装Python launcher或勾选“Add Python to PATH”。下载：https://www.python.org/downloads/windows/
3. 双击 Install_Windows.bat。首次联网安装固定版本依赖，随后检查模型文件及147个模型对象。此步骤可能需要几分钟；完成后无需每次重装。
4. 双击 Start_Windows.bat 打开中文界面。先点击“载入示例”，再点击“运行预测与筛选”。
5. 使用“选择 CSV / TSV”导入自己的化合物。SMILES是必需输入；名称、CAS仅是标签，不会联网解析为结构。CSV可由Excel另存；本版不直接读取XLSX。
6. 可直接每行粘贴一个SMILES。文件列名不是SMILES/Name/CAS时，在下拉框中选择对应列。
7. 运行后查看“化合物汇总”和“终点明细”。双击终点行查看效力区间、证据来源和未入选原因。结果会自动保存到选定目录下本次运行的独立文件夹。

输入
examples/demo_compounds.csv为可直接使用的示例。
CSV以英文逗号分隔；TSV以制表符分隔、后缀为.tsv。支持UTF-8、GB18030及带BOM的UTF-16。每次最多2000行，内部按100个有效结构分批运行。
无效SMILES和未定义原子会标记并跳过；其他有效行继续预测。相同结构的不同输入行会分别保留。盐类按冻结模型取主要片段并中和，标准化母体结构会随结果输出。结构未知的混合物不宜用任意代表SMILES代替，除非明确说明研究假设。

默认筛选（与论文区分实测证据和模型线索的写法一致）
17个核心EATS终点全部参与评估，不预先只挑一个报告终点。
数据库路径：严格质控数据库pAC50≥5.5。
模型路径：该终点无严格或较宽质控实测效力；校准活性概率≥0.65；联合适用域内；报告ROC-AUC≥0.70且PR-AUC高于训练集阳性比例；终点未暂停用于模型候选筛选。
ESR2拮抗、TSHR/TRHR激动和两个定向类固醇生成终点保留预测输出，但不提升为模型候选。数据库证据不受这些模型性能门槛限制。
24个辅助终点独立展示，不直接驱动EATS筛选。
这里的筛选是已冻结模型之上的论文应用规则，不是重新训练模型，也不是改变模型内部原有的置信分级。原模型的单一“代表终点”汇总仍存于原始模型输出中，阅读优先名单请以中文汇总和全部17终点筛选为准。

输出文件
化合物汇总.csv：每个输入一行，显示关注终点和两类入选数量。
全部EATS终点.csv：每个有效输入17行，包含适用域、实测/预测效力及区间、终点性能和筛选理由。
入选终点配对.csv：全部达到筛选条件的化合物–终点配对。
输入检查.csv：无效结构和多片段/描述符处理的说明。
结果报告.html：本地可查看、打印或打印为PDF的简洁报告。
results.json：完整GUI结果及运行环境记录。
原始模型输出/：冻结预测器的41终点、17核心、24辅助及原有代表终点汇总。除恢复用户名称/CAS和分批合并外，不改动模型数值。
运行日志.txt和界面运行日志.txt：排查错误使用。中断或失败的运行没有completed结果，不应当作完整预测。
用户原始输入和本次请求另存为input_日期时间目录。文件只留在本机；预测不查询或上传外部服务。

如何读结果
“数据库证据”指匹配母体结构已有体外测定效力，不代表本次实验已测得该毒性。
“模型候选”指值得后续确证/迁移/生物活性试验的线索，不是内分泌毒性确证。
“未达到本轮筛选条件”不能解释为安全或无活性。
pAC50=−log10(AC50，单位mol/L)，与预测活性概率不同。弱效力模型的数值和区间只作辅助，不能作为精确毒性定量。
对含多个片段或母体重原子数>60的结构，会提示原模型的处理方式；请结合标准化母体结构检查是否适合研究对象。
各终点性能及外部转移能力不同；所有41终点均获外部验证的说法不成立。详见docs中的原始模型卡。

固定版本依赖见requirements.txt。原包记录Python3.13；本GUI交付测试使用Python3.12.14，关键依赖版本与原冻结环境一致。

macOS/Linux
使用Python3.12或3.13创建环境：python3 -m venv .venv
安装：.venv/bin/python -m pip install --only-binary=:all: -r requirements.txt
检查：.venv/bin/python selfcheck.py
启动：.venv/bin/python app.py
Linux需要发行版提供的Tk/Tcl图形组件（如python3-tk）和桌面显示环境；macOS建议使用python.org提供的Python。

命令行批量运行
使用worker.py --request request.json；JSON字段示例：
{"input":"D:/compounds.csv","output":"D:/EDC_results/new_run","smiles_col":"SMILES","name_col":"Name","cas_col":"CAS"}
output目录应为尚不存在的新目录，以避免覆盖既有结果。
